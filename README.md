# Round Timer

Timer a round per boxe, MMA, HIIT ed EMOM. Pagina singola, nessuna dipendenza
esterna: funziona anche offline una volta caricata.

## Funzioni

- Durata round, pausa e numero di round configurabili, con preset rapidi
- Anello di progresso, colori distinti per round / pausa / completato
- Segnali acustici: avvio, conto alla rovescia degli ultimi 3 secondi,
  cambio fase, fine allenamento
- Wake lock: lo schermo resta acceso mentre il timer gira
- La configurazione viene salvata nel browser
- Scorciatoie: `Spazio` pausa · `R` reimposta · `Esc` indietro

## Uso in locale

Apri `index.html` in un browser. Non serve build né server.
